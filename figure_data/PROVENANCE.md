# figure_data/ — provenance

Contract between the two build stages: `make tables` writes this directory, and `make figures` reads only from it. It is committed to git so that `make figures` runs from a fresh clone with no model fitting.

One line per file: the stage-1 script that writes it, or `committed - no producer in this repo` with what is known about its origin. Files with nothing known are marked **unknown** rather than guessed.

Running `make tables` rewrites most of these files, leaving the working tree dirty here. `make verify-tables` checks that they re-derive.

**The four section counts below sum to the number of committed non-`.md` files in this directory**: 87 stage 1 + 6 opt-in discordance cache + 3 opt-in permutation null + 2 opt-in vignette panel c = **98**. The total is verifiable by summing rather than by trusting the individual counts.

```bash
git ls-files figure_data | grep -vc '\.md$'
```

Opt-in files are written by targets outside `make tables`, so a passing `verify-tables` confirms only that they are unchanged, not that they re-derive. `REPRODUCIBILITY.md` records which have been regenerated under current pins.
